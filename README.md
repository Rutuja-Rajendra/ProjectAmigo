# 🎙️ Project Amigo – AI Voice Assistant

Amigo is an AI-powered personal voice assistant built using Java, Spring Boot, JavaScript, HTML, and CSS, integrated with Google's Gemini AI.

It allows users to interact through voice, ask questions, and receive natural AI-generated responses.

## ✨ Features

- 🎤 Voice input using browser speech recognition
- 🤖 AI-powered responses using Gemini
- 🔊 Voice output using browser speech synthesis
- 🌐 Web-based user interface
- ⚡ REST API built with Spring Boot

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript
- **AI Integration:** Google Gemini API
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites
- Java 17 or compatible Java version
- Maven
- A Google Gemini API key
- A modern browser with speech recognition support

### Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
   ```

2. Set the `GEMINI_API_KEY` environment variable with your Gemini API key.

3. Open the project in Spring Tool Suite or another compatible Java IDE.

4. Run `AmigoApplication.java`.

5. Open your browser and visit:
   `http://localhost:8080/`

## 🔐 Security

Keep your Gemini API key private. Never commit API keys or other secrets to GitHub.
